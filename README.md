# Colindres Cell — Página web

Sitio estático listo para GitHub Pages.

## Archivos
- `index.html` — página principal.
- `style.css` — diseño responsive.
- `config.js` — **archivo principal para editar datos**.
- `assets/logo.jpg` — logo enviado como referencia.
- `assets/flyer.jpg` — volante enviado como referencia.

## Cómo editar
Abre `config.js` y cambia:
- teléfono de WhatsApp
- dirección
- enlace de Facebook
- enlace de Instagram
- enlace de TikTok
- enlace de Google / Google Maps
- productos

También puedes cambiar textos y estilos directamente en `index.html` y `style.css`.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `colindres-cell`.
2. Sube todos los archivos manteniendo la carpeta `assets`.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guarda y espera a que GitHub publique el sitio.

La URL quedará con esta estructura:
`https://TU-USUARIO.github.io/colindres-cell/`

## Compatibilidad
Está construido con HTML5, CSS y JavaScript sin frameworks, por lo que funciona en navegadores modernos como Google Chrome, Safari, Firefox, Edge y navegadores móviles.

## Nota
GitHub Pages es alojamiento estático. No se deben poner contraseñas, datos bancarios u otra información confidencial en los archivos públicos.
